# Fuel Cost Share App

A Flutter app that splits the fuel cost of a trip between travellers, with an optional tip.

## Features
- Enter the total fuel cost
- Choose the number of travellers with the + / − buttons (minimum 1)
- Pick a tip from 0% to 50% with the slider, in steps of 10%
- See the tip amount and the total cost per traveller, updated live

## Running the App
flutter run
